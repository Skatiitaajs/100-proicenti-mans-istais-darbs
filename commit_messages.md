# Ieteicamie GitHub commit ziņojumi

Projektam vēlams neveidot tikai vienu commit. Labāk darbu sadalīt vairākos loģiskos soļos, lai skolotājs redzētu darba gaitu.

1. `Izveido projekta pamatstruktūru`
2. `Pievieno random bibliotēkas funkciju piemērus`
3. `Izveido konsoles izvēlnes programmu`
4. `Pievieno tkinter vizuālo programmu`
5. `Pievieno random bibliotēkas cheat sheet`
6. `Papildina README ar kritērijiem un secinājumiem`
7. `Pievieno projekta plānu un pašpārbaudi`

## Ieteicamā secība GitHub darbam

```bash
git init
git add .gitignore README.md requirements.txt
git commit -m "Izveido projekta pamatstruktūru"

git add examples/
git commit -m "Pievieno random bibliotēkas funkciju piemērus"

git add main.py
git commit -m "Izveido konsoles izvēlnes programmu"

git add gui.py
git commit -m "Pievieno tkinter vizuālo programmu"

git add cheat_sheet.md
git commit -m "Pievieno random bibliotēkas cheat sheet"

git add README.md commit_messages.md project_plan.md assessment_checklist.md github_setup.md
git commit -m "Pievieno projekta plānu un pašpārbaudi"
```
